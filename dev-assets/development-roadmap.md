# FloraScan — 2-Day Development Roadmap

## Day 1 — Core Features

- Create Android Studio project
- Build simple home screen
- Add gallery image selection
- Add image preview
- Connect Pl@ntNet API
- Send image for identification
- Parse API response
- Show result:
  - Common name
  - Scientific name
  - Confidence
  - Family
  - Genus
- Add "Identify Another Plant" button

## Day 2 — Final Features

- Add camera support
- Add loading indicator
- Add error handling
- Add low-confidence handling
- Improve UI
- Add app icon and splash screen
- Test camera and gallery flow
- Test multiple plant images
- Clean code
- Write README
- Record demo video
- Prepare final screenshots

## Simple App Flow

Home
→ Camera / Gallery
→ Preview
→ Identify
→ Pl@ntNet API
→ Result

## Tech Stack

- Android Studio
- Java
- XML
- Retrofit
- Gson
- Glide
- Pl@ntNet API

## Goal

Day 1: Make it work.

Day 2: Make it polished and ready to submit.
